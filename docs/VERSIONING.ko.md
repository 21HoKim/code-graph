# 버전 번호

[README](../README.ko.md) · [English](VERSIONING.md) · [사용 설명서](GUIDE.ko.md) · [변경 기록](../CHANGELOG.md) · [릴리스](https://github.com/21HoKim/code-graph/releases)

CodeGraph 버전은 **0.5.0**처럼 숫자 세 개, **MAJOR.MINOR.PATCH**로 되어 있어요.

| 자리 | 0.5.0에서 | 올라가는 때 | 정하는 방법 |
| --- | --- | --- | --- |
| MAJOR | 0 | 쓰던 방식이 더는 그대로 동작하지 않을 때: 설정이나 `.codegraph.json` 키가 없어지거나 이름이 바뀔 때, 파일 형식이 바뀌어 예전 파일을 못 읽을 때 | 직접 |
| MINOR | 5 | 눈에 띄는 새 기능이 생길 때: 새로운 실행 방식, 화면, 프로젝트 파일(실시간 보기, `.codegraph.json`, 컨테이너별 보기) | 직접 |
| PATCH | 0 | 그 밖에 확장이 바뀌는 모든 경우: 버그 수정과 작은 개선 | 릴리스할 때마다 자동 |

그래서 **0.4.1 → 0.4.2**는 그냥 받아도 되는 수정이고, **0.4.x → 0.5.0**은 [변경 기록](../CHANGELOG.md)에서 볼 만한
새 기능이 있다는 뜻이에요. MAJOR 숫자가 바뀌면 설정을 확인해 보세요.

## 1.0 이전

MAJOR가 **0**인 동안은 CodeGraph가 아직 자라는 중이라, MINOR 버전에서 기본 동작이 바뀔 수도 있어요. 예를 들어
0.5.0에서는 실행 & 추적의 20초 시간 제한을 없앴어요(이제 프로그램이 끝나거나 멈추기를 누를 때까지 실행돼요). 이런
변경은 모두 변경 기록의 해당 버전 아래에 적어 둬요.

**1.0**부터는 1.x 버전 내내 설정, `.codegraph.json` 키, 추적·그래프 파일 형식이 호환되게 유지하고, 이걸 깨는 변경은
2.0에서만 해요.

## 버전이 나가는 과정

확장을 바꾸는 커밋(`src/`, `runtime/`, `media/`, `l10n/`, `schemas/`, `package.json` …)이 `main`에 올라가면 *Publish*
워크플로가 릴리스해요.

1. 타입 검사와 테스트를 돌려요. 하나라도 실패하면 아무것도 릴리스하지 않아요.
2. 버전을 정해요(`scripts/release-version.mjs`). `package.json`의 버전이 지금까지의 모든 릴리스보다 높으면 그 버전,
   아니면 가장 최근 릴리스의 다음 PATCH예요.
3. 확장을 패키징해서 VS Code 마켓플레이스에 올리고, `vX.Y.Z` GitHub 릴리스에 붙여요. 릴리스에는 이전 릴리스 이후의
   변경 전체로 가는 링크가 들어가요.

새 MINOR나 MAJOR 버전은 `package.json`에 그 버전을 적고(`npm version minor --no-git-tag-version`) 올리면 나가요. 그다음
변경까지는 릴리스할 때마다 PATCH만 올라가요. 0.5.0 다음은 0.5.1, 0.5.2, … 그래서 마켓플레이스에는 0.5.3이 있어도
저장소의 `package.json`은 0.5.0으로 남아 있어요. 정확한 버전은 배포하는 패키지에만 기록돼요.

문서만 바꾼 커밋(`README`, `docs/`)은 릴리스하지 않아요. README와 CHANGELOG의 변경은 다음 릴리스 때 마켓플레이스 페이지에
반영돼요.

## 무엇이 바뀌었는지 보는 곳

- [CHANGELOG.md](../CHANGELOG.md): MINOR 버전과 눈여겨볼 PATCH 버전마다 한 절씩.
- [GitHub 릴리스](https://github.com/21HoKim/code-graph/releases): 모든 버전과 그 `.vsix`.
- 마켓플레이스 페이지의 *Version History* 탭. 확장은 VS Code가 알아서 업데이트하고, 예전 버전으로 돌아가려면 확장의
  ⚙ 메뉴에서 *다른 버전 설치…*를 고르거나 릴리스의 `.vsix`를 설치하면 돼요.

## 그 밖에 보이는 번호

| 위치 | 번호 | 뜻 |
| --- | --- | --- |
| 추적 원본 파일(`.jsonl`)의 첫 줄 | `code-graph-trace/1` | 추적 형식 버전. 예전 CodeGraph가 새 형식을 못 읽게 바뀔 때만 올라가요 |
| *그래프를 JSON으로 내보내기*나 `code-graph <dir> -o`로 만든 그래프, `code-graph trace -o`로 만든 실행 기록 | `"schema": 1` | 그 파일들의 형식 버전 |
| `package.json` → `engines.vscode` | `^1.85.0` | 확장이 돌아가는 가장 오래된 VS Code 버전 |
